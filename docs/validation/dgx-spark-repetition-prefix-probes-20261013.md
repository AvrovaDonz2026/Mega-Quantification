## 共同前缀探针

MSE W4A4、max W4A4、源 BF16 各执行三个请求：原输入的 16-token cold replay，
以及指定七 token 前缀后的 1-token 和 512-token 续写；共 **9 请求、1587 个
生成位置**。三组 16-token replay 均匹配各自绑定既存原生记录的前 16 tokens。
这不证明冷启动与原始 incremental 路径具有相同状态；已审计的候选分数路径存在差异。

对每个模型分别比较预算 1 与 512：其首步选择及完整有序五候选分数行均完全一致；
补充审计确认其 canonical 字节一致。这是**跨预算首步一致性**，没有估计同预算重复请求的稳定性。
所有请求均以 length 结束；未出现 thinking-end、EOS 或所检查的精确循环。
512-token 续写的最终停止与后续循环行为仍是被预算截断的未知量。

## 语义历史探针

两个已保存的 MSE / max 历史前缀分别送入三模型，每个请求预算 256 tokens：
共 **6 请求、1536 个生成位置、7680 个请求候选位置分数**，全部核验通过。
请求采样与冻结计划一致；所有请求 cached tokens / retractions 均为 0 / 0，
首步均选择各历史源保存的后继 token。

六条续写全部以 length 结束，没有 thinking-end、EOS 或所检查的精确循环；
不能据此认定已经脱离语义反复或将来会停止。对 max 来源历史，三目标续写与
**来源记录后续输出**的最长共同前缀均为 **22 tokens**；其中两组目标之间的
pairwise 前缀为 23 tokens，比较对象不同，不能替代来源记录的 22-token 结论。

## 证据范围

这里的 cold prefill 不重建原始 FP8 KV / SSM incremental 状态；包括 BF16 接受
指定历史前缀的续写，也不能等同其自然轨迹。前 16 tokens 一致或首步一致不证明
状态与分数路径相同。全位置核验检查的是返回的处理后 logprobs，未检查完整原始
logits 张量；零缓存与 flush gate 不证明全主机/GPU 隔离或每个权重字节。
短预算内没有精确循环不能排除语义反复、近似重复或更晚循环。这些结果不建立
自然首次分叉归因、量化循环因果、通用停止恢复或模型质量排序。
